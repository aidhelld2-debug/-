# BT Закрепитель — Android TV / YaOS

Экспериментальное приложение для DEXP 55UCY1-G (Android 11 / Яндекс ТВ), предназначенное для восстановления Bluetooth A2DP соединения с закреплённой колонкой.

- Привязка уже сопряжённого Bluetooth-устройства.
- Фоновая служба с интервалом повторных попыток 20 секунд.
- Автозапуск после включения ТВ, проверка разрешений и журнал диагностики.
- Русский интерфейс для пульта.

⚠️ В Android 11 метод BluetoothA2dp.connect скрыт от обычных приложений и может блокироваться прошивкой. Поэтому автоматическое подключение **не гарантируется** без проверки на реальном телевизоре. Не предназначено для обхода привилегий ОС.

Для сборки откройте GitHub → Actions → Build BT Zakrepitel APK → Run workflow или дождитесь запуска по push. APK доступен в Artifacts после успешной сборки.

Первоначальное сопряжение выполняется в системных настройках телевизора.
