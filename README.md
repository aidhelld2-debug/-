# BT Закрепитель — DEXP / Яндекс ТВ (Android 11)

Русскоязычное тестовое APK для закрепления выбранной Bluetooth-колонки и попыток восстановить A2DP-подключение каждые 20 секунд.

## Версия 0.2-test
- **📌 Красная кнопка закрепления слева от названия устройства**.
- В списке показываются **только устройства, обнаруженные прямо сейчас при поиске**, а также фактически подключённые A2DP-устройства, которые сообщает ОС. Сохранённый за многие месяцы список сопряжений больше не отображается.
- Для закрепления устройство должно одновременно быть обнаружено рядом (или подключено) **и уже сопряжено**. Если оно не сопряжено — сначала используйте настройки ТВ.
- При запуске и каждые 3 секунды, пока открыта программа, проверяются необходимые разрешения. Недостающие разрешения показываются в **неотменяемом диалоговом окне**, которое предлагает системное подтверждение или открывает соответствующие настройки. Отдельной панели разрешений на главном экране нет.
- Android 11: для поиска требуется разрешение точной геолокации и включённая служба местоположения (это требование Android; координаты приложением не собираются). Android 12+: «Устройства поблизости» (BLUETOOTH_SCAN / BLUETOOTH_CONNECT).
- Исключение из энергосбережения запрашивается *как рекомендация*, поскольку некоторые прошивки YaOS не позволяют его выдавать. Приложение не может гарантировать непрерывную работу после принудительного завершения прошивкой.
- Фоновая служба, автозапуск после полной загрузки и журнал диагностики сохранены.

⚠️ **Ограничения:** Bluetooth-сканирование обнаруживает устройства только когда те отвечают на запросы обнаружения. Некоторым уже сопряжённым колонкам требуется режим обнаружения, хотя они находятся рядом. Само переподключение A2DP зависит от закрытых системных интерфейсов прошивки YaOS; оно может не сработать без системных привилегий.

## Сборка APK
GitHub → Actions → **Build BT Zakrepitel APK**. После успешного запуска скачайте **BT-Zakrepitel-APK** в разделе Artifacts. В ZIP находится `app-debug.apk`.

Репозиторий создан для DEXP 55UCY1-G / Android 11.
