# BT Закрепитель — Android TV / YaOS

Тестовое Android TV-приложение для DEXP 55UCY1-G (Android 11) с автоматическими повторными попытками подключения закреплённого Bluetooth-аудиоустройства.

## Версия 0.3-test — интерфейс для телевизора

- Двухколоночный телевизионный экран: **доступные устройства слева, состояние и управление справа**, как в утверждённом макете.
- Крупные карточки и **яркий бирюзовый фокус** при перемещении телевизионным пультом.
- **Красная кнопка 📌 слева** от названия каждого обнаруженного устройства.
- Специальные **офлайн-иллюстрации** (не удалённые фото) только для Bluetooth-имён:
  - `JBL Flip 6` — синяя колонка;
  - **`Станция Мини 3 Про`** — Яндекс Станция Мини 3 Про. Поддерживаются также `Яндекс Станция Мини 3 Про` и `Mini 3 Pro`.
- Для других устройств — универсальная иконка Bluetooth, без изображения конкретной модели.
- Список формируется из *недавно обнаруженных* устройств и текущих A2DP-соединений, а не из всей истории сопряжений. Закреплять можно лишь уже сопряжённое устройство из этого списка.
- Необходимые Bluetooth/Location-разрешения проверяются при открытии и регулярно (3 секунды). При их отсутствии предлагается системный диалог или переход в настройки, отдельной панели разрешений на экране нет.
- При включённом мониторинге попытка восстановить A2DP-соединение выполняется каждые 20 секунд. Работа службы в фоне и попытка запуска после полной загрузки ТВ сохранены.

## Ограничения

- В Android 11 для поиска Bluetooth Classic нужен доступ к геопозиции и включённая геолокация, хотя координаты приложение не собирает.
- Не каждое включённое Bluetooth-устройство отвечает на стандартное обнаружение. Если устройство не видно, попробуйте режим сопряжения.
- Аудиоподключение реализовано через скрытый API `BluetoothA2dp.connect`, который **может быть заблокирован YaOS**. Успешная сборка не гарантирует доступ на конкретном ТВ.
- Фоновую службу может ограничивать телевизионная прошивка; системные ограничения невозможно отменить только выдачей пользовательских разрешений.
- Иллюстрации — нарисованные внутри проекта, без дополнительных скачиваний, и не являются официальными изображениями производителей.

## APK

[Сборки GitHub Actions](https://github.com/aidhelld2-debug/-/actions/workflows/build-apk.yml) → откройте последнюю успешную сборку → **Artifacts → BT-Zakrepitel-APK**. В архиве находится `app-debug.apk`. Можно устанавливать поверх предыдущей версии без удаления данных приложения.
