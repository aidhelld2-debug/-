# Аудио ТВ 1.2 — более громкое усиление без дополнительной компрессии

Для DEXP с Яндекс ТВ. Объединены усиление и закрепление Bluetooth.
Сохраняются одобренная пользователем иконка, иллюстрации реальных колонок, адаптация к ТВ-пульту, Bluetooth-мониторинг и автозапуск.

## Усиление — обновлено
| Режим на экране | Старый заданный коэффициент | Новый заданный коэффициент |
|---|---|---|
| ×1,5 | +3,52 дБ | +6 дБ |
| ×2 | +6,02 дБ | +10 дБ |
| ×3 | +9,54 дБ | +16 дБ |
| ×4 | +12,04 дБ | +20 дБ |

Кнопки ×1,5–×4 — **приблизительные ориентиры воспринимаемой громкости**, а **не гарантированные коэффициенты**. Реальное увеличение зависит от фильма, динамиков, усилителя телевизора и внутреннего ограничения пиков Android. Параметры в таблице — заданные в Android уровни, а не измеренный акустический результат.

**Никакого нового динамического компрессора или звукового процессора не добавлено.** По-прежнему используется `LoudnessEnhancer(0)`, в котором заложено собственное ограничение сигнала; отключить его без смены механизма обработки нельзя.

### Безопасность
В режимах +16 и +20 дБ могут возникать искажения, хрипы и перегрузка динамиков. Начните с ×1,5; при искажении сразу уменьшите усиление.

### Установка и подпись
Пакет этой версии `ru.frolov.tvaudiocenter.louder12` намеренно отличается от 1.1. GitHub Actions генерирует временную debug-подпись, поэтому подписанная иначе сборка не может обновить прежнюю поверх без удаления. Новая версия устанавливается **рядом** с 1.1 без потери его настроек. После установки перенесите закрепление Bluetooth в новую версию и выключите мониторинг и усиление в старой, чтобы избежать конфликтов. Прямой перенос настроек между разными пакетами без привилегий Android не реализован.

### Ограничения
Автозапуск и постоянная фоновая работа зависят от ограничений конкретной прошивки; скрытый системный `BluetoothA2dp.connect` может быть заблокирован. Частота фонового резервного JobScheduler приблизительная — система может сдвигать выполнение.
