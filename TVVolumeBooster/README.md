# Аудио ТВ (DEXP / Яндекс ТВ) · экспериментальная объединённая версия

Два инструмента в одном Android TV приложении:
1. Усилитель громкости с четырьмя режимами ×1,5 / ×2 / ×3 / ×4. Используется уже работавший на телевизоре механизм LoudnessEnhancer(0), включая фоновую службу и сохранение режима.
2. Закрепление Bluetooth-колонки. Постоянный список сопряжённых устройств, красная кнопка закрепления, картинки синей JBL Flip 6 и Станции Мини 3 Про. Кнопка обновления, поиск новых устройств, открытие настроек Bluetooth, журнал состояния и проверки через фоновую службу каждые 20 секунд.

Обе части работают независимо: можно выключить усиление и оставить закрепление, или наоборот.

## Сборка

GitHub Actions: workflow **Build TV Audio Center APK**. При успешной сборке откройте артефакт **TV-Audio-Center-APK**, внутри **TV-Audio-Center.apk**.

**Ограничения:** BluetoothA2dp.connect — скрытый системный API, и YaOS может заблокировать его вызов. Программа сообщает о блокировке, но не может обойти её без системных прав. Поиск новых устройств иногда требует разрешения геолокации на Android 11. Автоматический запуск служб может ограничиваться прошивкой.

**Безопасность:** для теста выбрано отдельное имя пакета ru.frolov.tvaudiocenter. Приложение устанавливается рядом с рабочим усилителем (ru.frolov.tvvolumebooster), не заменяет его и не сбрасывает настройки. После успешной проверки объединённой версии старую программу можно удалить вручную. Прошивка может ограничивать одновременные изменения глобального аудиоэффекта — тестируйте с отключённым старым приложением.

Варианты ×3/×4 могут давать цифровую перегрузку и искажения. Убавьте уровень при хрипах. Результат во всех сторонних видеоприложениях не гарантируется всеми моделями Android TV.
