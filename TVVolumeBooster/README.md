# Усилитель громкости ТВ · DEXP / Яндекс ТВ

**Экспериментальная APK-сборка (0.1-test).** Не проверена на физическом телевизоре.

- Четыре фиксированных коэффициента: ×1,5 (+50%), ×2 (+100%), ×3 (+200%), ×4 (+300%).
- Отдельная кнопка выключения, управление с пульта (D-pad), ТВ-интерфейс.
- Служба удерживает эффект после выхода в другое приложение; выбранный режим восстанавливается после перезапуска ТВ, если YaOS позволяет фоновые службы.
- Без интернета, аккаунта, рекламы и записи звука.

## Честное ограничение

Приложение пытается подключить Android LoudnessEnhancer к **глобальной аудиосессии 0**. Этот способ уже объявлен Android устаревшим и может быть запрещён прошивкой. Часть видеоприложений / аппаратный аудиотракт / HDMI passthrough могут обходить этот эффект. **Гарантировать усиление во ВСЕХ приложениях без root или системных привилегий нельзя.**

Коэффициенты означают запрашиваемое цифровое усиление амплитуды (352/602/954/1204 mB), а не гарантированный рост воспринимаемой громкости. Видеозвук может начать искажаться; высокие уровни могут навредить динамикам. Начните с ×1,5.

## Сборка

GitHub Actions → **Build TV Volume Booster APK** → артефакт **TV-Volume-Booster-APK**. В ZIP — файл **TVVolumeBooster-debug.apk**.

Локально: Java 17, Android SDK 35, Gradle 8.7, команда в этой папке: gradle assembleDebug.
